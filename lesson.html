01

两个数字就够了

所有直线都能写成同一副样子：

y = m x + b

  • m 叫斜率，是这条线的爬升速度：每向右走一步，它抬高多少。m = 3 就是"右一格、上三格"；m = −0.5 就是"右一格、下半格"。
  • b 叫 y 截距，是它出发时站在哪：x = 0 时线在竖向轴上那个位置。

换个说法：b 是出发时你站的高度，m 是你每走一步的抬升速度。站得高不高和走得快不快，是两件互不相干的事——这正是它能被拆成两个数字的原因。

02

图和式，来回读

虚线三角就是在读 m：先向右一格，再看要抬高多少格。

  • 图 → 式：挑两个好读的点，m = (y₂ − y₁) / (x₂ − x₁)，再把其中一个点代回去求 b。
  • 式 → 图：先在竖向轴上点出 b，再按 m 走一格落第二个点，两点连成线。
  • x 截距：让 y = 0 解出 x，得到 −b / m。它是线穿过横向轴的位置，和 b 是两个不同的点。
03

两道例题，看怎么读

例 1 · 从图读出式子

直线经过 (0, 3) 和 (4, 7)，求它的方程与 x 截距。

先算斜率：m = (7 − 3) / (4 − 0) = 1。意思是右一格、上一格。

(0, 3) 就在竖向轴上，所以 b = 3，不用再算。

方程 y = x + 3。令 y = 0 得 x = −3，x 截距是 −3，图上确实在原点左边三格。

例 2 · 一般式先变形

把 3x + 2y = 12 读成一条直线。

先孤立 y：2y = −3x + 12，两边除以 2。

得 y = −1.5x + 6：m = −1.5（右一格、下 1.5 格），b = 6。

x 截距 = −6 / (−1.5) = 4。代回原式验证：3·4 + 2·0 = 12，对。

04

三个最常被扣分的地方

  • 把 x 截距当成 b。b 在竖向轴上，x 截距在横向轴上，数值常常互为相反数。题问哪个，答哪个。
  • 斜率符号反了。(y₂ − y₁) / (x₂ − x₁) 上下顺序必须一致；只颠倒一处就整体变号，图上会从"上坡"变成"下坡"。
  • 平行当成同一条。"与 y = 3x − 1 平行且过 (2, 5)"：5 = 6 + b 得 b = −1，算出来就是 y = 3x − 1，与原线完全重合。平行只保证 m 相同，b 得另算。
05

落笔前的一分钟检查

  • 我交上去的是 y = mx + b 的形状，不是 x = …
  • m 的符号和图像一致：左低右高就是正的。
  • 题目问的是 y 截距还是 x 截距，我答的是同一个吗。
  • 如果是应用题，单位有没有跟着数字一起写。

读到这里，这一节的 9 道题基本都能落笔了。做题时允许回头翻这一页。

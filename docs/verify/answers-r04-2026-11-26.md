## 2. 三处真错（已改）

### 2.1 R04-004（T24 #4，grid）29.68 → **32**，同时修图形端点

- 题干：线段是直角三角形的一条腿，面积 `48√13`，求另一条腿
- 原书图（p142 右栏）：线段端点实为 **(-5,3)→(4,9)**；我们旧 spec 写成 `(5,9)`，于是腿长算成 `2√34`，答案 `29.68`——**自洽但错**
- 修正后腿长 `√117=3√13`，另一腿 `= 2·48√13/(3√13) = 32`，与印刷答案页 `32` 一致
- `data/figures.js` `R04-004` 两条 series 的点同步改为 `[[-5,3],[4,9]]`（矢量重画，无截图）

### 2.2 R04-063（T25 #3，grid）49 → **123**

- 题干：Q,R,S,T 在 PV 上；RU 与 SX 交于 W；∠SQX=48°、∠SXQ=86°、∠SWU=85°、∠VTU=162°，求 ∠TUR
- ∠QSX=46°；RU 相对 PV 方向 = 46−85 = **39°**；∠VTU=162° ⇒ TU 相对 PV = 18°；∠TUR = 180−18−39 = **123**
- 旧值 49 出自错链 `180−85−46`（把 ∠SWU 当成了三角形 SWU 的一个内角）
- 印刷答案页 = 123，独立复算 = 123，两路一致

### 2.3 R04-064（T25 #4，grid）83 → **97**

- 题干：三线 r, s, t 相交；s 竖直，s 与 t 的钝角 106°，t 与 r 夹角 23°，求 x
- ∠(s,t) = 180−106 = 74° ⇒ t 与水平 16°；r 与 t 夹 23° ⇒ r 与水平 7°；x 是 s 与 r 的**钝角**（图上 x° 标在 s 左侧 r 上方）= 90+7 = **97**
- 旧值 83 是同一个角的补角（锐角一侧），与原图标注位置不符
- 印刷答案页 = 97

# 同题干 ≠ 同一道题：重复组里"被并成一笔"的六处订正（2026-11-27）

`tools/dup_groups.mjs` 的口径一直是"题干归一相同即视为同一题"。这一口径本身没错（题库里大量同题确实重复收录），但它有一个副作用：书上有几处**题干一字不差、数据完全不同**的独立题，被并进了同一组 alias，错题本就按 alias 把两道不同的题算成一笔。

逐组按原页核过之后，分家清单落成 `data/dup-splits.json`（`tools/dup_groups.mjs` 直接读它），alias 165 → 157，重复组 142 → 140。

## 顺带修的两处真错

1. **`SR-099` 选项底数错**（02 册 p55 T10 #15，02 册 p55 无扫描，用讲义同题 `JY3-097` 交叉核，讲义 p135 #15 原页）：库里存的是 `50(2)^{x+1}`／`80(2)^{x}`／`128(2)^{x-1}`／`205(2)^{x-2}` —— 这四个式子在代数上并不等价（100·2^x、80·2^x、64·2^x、51.25·2^x），不可能同时是同一个函数的等价形式；讲义原页印的是 `50(1.6)^{x+1}`／`80(1.6)^{x}`／`128(1.6)^{x-1}`／`204.8(1.6)^{x-2}`（四个都等于 80·1.6^x，且 k=f(1)=128 正好在 C 里当系数）。已按讲义原页把 SR-099 的四个选项改回 1.6 系。
2. **两行选项被压成一行**（`SR-214`、`TD-12-27`）：库里选项用 `\n` 分成两条方程，但 `.drill-choice-text` 没有 `white-space:pre-wrap`，浏览器把换行当空格吞掉，渲染成 `x + y = 1600.25x + 0.41y = 0.32(160)`（数字被粘成 "1600.25x"）。已给 `.drill-choice-text`（含 `.answer-compare`）补 `pre-wrap`，并把 `TD-12-27` 的四个选项按练习册 P26 原页改成两行。

### 全库结构自检（本轮新增，防"参数自相矛盾"）

对 243 条 spec 跑了一遍静态规则：标签是否越出轴范围、`origin:'O'` 是否落在 x 包含 0 的图上、`step`/`minor` 是否 ≤0、`axesAt` 与范围是否互斥。结果 **0 条异常**（先前报出的 3 条是检查脚本自己用了 x 的边界比 y 标签，误报）。

### 坐标平面：两轴必须过原点（本轮发现的结构性错，已全库修正）

原书所有坐标平面都是两轴在原点相交、标 `O`（少数标 `0`），我们此前有 13 张画成了"x 轴贴画框底边、y 轴贴左边框"。已在 `figures.js` 里改成默认行为：**只要 0 落在轴范围内，轴就落在 0 上**（`axesAt:'border'` 才贴边），数据侧不再逐张打补丁。

# 两道选图题的原页证据（供图形线校正）· 2026-11-25

`docs/choice-figures-12.md` 里标了「待核」的两条，原页扫描已补：`workbook-p89-td-22-14.png`（练习册 P89 #14）、`workbook-p175-td-33-19.png`（练习册 P175 #19）。下面是按原页逐格读出来的事实，供码农 α 校正向量 spec；答案仍以答案页为准（TD-22-14 = B，TD-33-19 = A）。

## TD-22-14（P89，40x + 30y = 600）
| 选项 | 坐标轴范围 | 直线 | 是否满足方程 |
|---|---|---|---|
| A | x 0–40，y 0–40 | 过 (0,15) 与 (20,0)，斜率 −0.75 | 否（400+450=850） |
| **B** | x 0–40，y 0–40 | 过 (0,20) 与 (15,0)（y = 20 − (4/3)x） | **是**（0+600=600） |
| C | x 0–20，y 0–20 | 过 (0,15) 与 (15,0)，斜率 −1 | 否（0+450=450） |
| D | x 0–20，y 0–20 | 过 (0,0) 与 (16,20)，单调上升 | 否（截距为 0） |

要点：**C 不是「与 B 同截距、窗口更小」**——C 的截距是 (0,15)/(15,0)，B 是 (0,20)/(15,0)，C 本来就与方程不符，可以当纯干扰项用。

## TD-33-19（P175，f(x)=0 有解 x=7，且 (x+5) 是因子）
四个选项都过 (−5,0) 与 (7,0)，差别在第三根：

| 选项 | 第三个零点（原页读数） | 形态 |
|---|---|---|
| **A** | **x = 3**（−5 穿轴向下、3 穿轴向上、7 穿轴向下） | 三次，两端异号 |
| B | x ≈ 0.7（落在 0 与 2 之间，不是 2） | 三次 |
| C | x = −2 处**相切（重根）** | 三次，含一个偶重根 |
| D | x = 4.5 处**相切（重根）** | 三次，含一个偶重根 |

以原页为准：A 与记录一致（−5、3、7）；B 的第三根不是 2（原页落在 0 与 2 之间，约 0.7）；C 的第三根不是 2.5，而是在 −2 处相切（偶重根）；D 的 4.5 相切与原记录一致。B、C 两条需按上表重画。

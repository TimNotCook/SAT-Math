## 三条硬规则

1. **同一时间只有一个人写 `data/jiangyi.js`**。α 在 1.6 期间，本包只是备料；谁拿到本包也不许先把空壳 id 写进主文件（半截数据会让 `npm test` 红）。
2. **图表真值只在原页**。表里的「图表风险」是按小节性质做的备料预判，不是验收结论；原页实际有什么就以什么为准，并回来修正风险等级。
3. **答案只抄答案页**。讲义侧用 p191–196；练习册 P246 是另一套（只服务 JY4 教材原题九题），两边绝不混用。

## 预留 id 怎么来的

- U3：`JY3-001` 起顺排 68 个（3.1 起、3.6 止）。
- U4：**从 `JY4-056` 起**，因为 `JY4-047…055` 已被教材原题九题（练习册 P200–207，`group:'textbook'`）占用；官方 4.1–4.5 的 52 道排到 `JY4-107`。想改成从 001 起，得先迁那 9 条题号，代价大于收益，不建议。
- 生成的 id 已在脚本里对 `JY_BANK` 现有 id 做过避让，全部未占用。

## 建议开工顺序

`3.1 → 3.2 → 3.5 → 3.6 → 3.3 → 3.4`（先单位小的、图表少的，把流程跑顺）→ `4.1 → 4.3 → 4.5 → 4.2 → 4.4`（先小题量几何节热手）→ 3.4 / 4.2 / 4.4 三节图最重，留到有矢量 spec 手感时再上。

## 录入注意

1. `source` 三段齐全：`讲义 p{页} #1` 这种形态，页码必须落在 p113–p125。
2. `answer` 逐字照抄 p194，不改写法（分数写成 `25/4 or 50/8 or 6.25` 就整串照抄）。
3. 每题存一张原页对照图 `docs/jiangyi-proof/{id}.png`，缺图测试直接红。
4. 录完跑 `python3 tools/gen_jiangyi_reconcile.py` 与 `npm test`，本节「已录 = 应有」才算结案。
5. **3.x 编号坑**：讲义用官方编号（3.1 等价表达式 / 3.2 运算 / 3.3 求解 / 3.4 图像 / 3.5 函数记号 / 3.6 建模）；练习册与题库的 3.x 整体比官方小 1。拿练习册材料交叉核对时**不要按同号取**，见 `docs/td-vs-official-unit3-map.md`。

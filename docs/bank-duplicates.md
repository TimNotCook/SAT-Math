# 题库重复题干台账（1009 题 + 讲义 45 题）

> 本表由 `node tools/dup_groups.mjs --doc` 生成，数字可复现；勿手改。

## 口径

1. **归一规则**：题干去首尾空白 → 连续空白压一个 → 引号统一为 `"` → 小写化。**不做**去标点、不做同义改写，宁可漏判不可错判。
2. **统计**：`重复组` = 归一后题干相同的组数；`多余副本` = 每组除 canonical 之外的份数；`两两对数` = 组内 C(n,2) 之和。
3. **canonical 优先级**：`U`（单元精编 / 单元卷）> `JY`（讲义复习）> `TD`（TD 教材）> `SP/SR`（练习册 / 专项）。同级按 id 字典序。
4. **显示保留 canonical**；同组其余成员在 `data/aliases.js` 里标 alias 指向 canonical，错题本按 alias 归并。
5. alias 是**数据层映射**，不改 1009 题题干文件（避免整文件 diff 噪音）；`data/aliases.js` 由 `--alias` 生成。

## 错题本归并规则

1. `wrong-page.js` 的 `questionById(id)` 先查 `window.TD_ALIAS[id]`，命中即换成 canonical 再取题；记录 map 的键因此恒为 canonical id。
2. 同一道题在「单元精编」错一次、在「练习册」再错一次，合并为**一条**错题记录，`attempts` 累加、`sources` 追加来源。
3. 只有 canonical 参与计数，alias 副本不单独出现在错题本列表里。

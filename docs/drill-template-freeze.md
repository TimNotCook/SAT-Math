## 2. 有意增加：只有这些

1. **每个选项行右侧一颗 ✕**（`.crossout-toggle`），绝对定位在选项卡右外侧。
   - 1280：`x=1054…1078`（CSS px），选项卡右边缘 `1050`。
   - 390：`x=362…386`（CSS px），选项卡右边缘 `358`，右边仍留 `4px`，不出视口。
2. 每个 `.drill-choice` 外面包一层 `.drill-choice-row`，只为给 ✕ 提供定位容器。
3. 划掉态：文字选项加灰色删除线；图形选项（`is-image-option`）整块压低透明度灰斜线 + 灰度化。
4. 成绩 / 结果页增加只读一行：`划掉：A、C`（模考英文层为 `Crossed out: A, C`），**没有按钮**。

**没有动**：字体、字号、行高、行间距、选项卡宽度、题号位置、`#appbar`、context bar、questionbar、题干、底栏、Mark for Review、判分、选中逻辑。模板冻结的 `!important` 一处未改。

## 6. 功能验收记录

| 项目 | 实测 |
|---|---|
| 划掉 ≠ 选中 | 划 A 后 `answer=""`；再选 B，A 仍划掉、B 为选中 |
| 不改 Mark | 划 A/B 后 `#btnMark aria-pressed=false`；单独点 Mark 变 true，划掉状态不变 |
| 按 qid 持久化 | `localStorage["tdsat_crossout_v1"]={"TD-11-01":["A","B"]}`；刷新后 A/B 仍在 |
| 切题 / Back | 第 1 题划 A，去第 3 题划 D，回第 1 题：A 在、第 3 题 D 也在，互不串题 |
| 快捷键 | `Shift+2` 划 B、`Shift+3` 划 C；输入框聚焦 / 草稿板打开时不触发 |
| 390 不挤掉 | 四行 ✕ 的 `right=386 < 390`；`scrollWidth=390`，无横向滚动 |
| 图形选项 | A 整块 `repeating-linear-gradient` 斜线 + `grayscale(.9)`；不是红色 |
| 模考交卷 | 交卷后结果页 `Crossed out: A, B`；`#resList .crossout-toggle` 数量 **0**，不可再改 |
| 做题成绩页 | `drill.html?sec=1.1&result=1` 显示 `划掉：A` / `划掉：D`，按钮数量 **0** |

## 7. 下次核对的人请注意

1. **不要把 ✕ 条带当成模板漂移**：1280 的 `x=1054…1078`、390 的 `x=362…386` 内的差异是预期。
2. 只要 **条带外出现任何像素差**，或行高 / 选项卡宽度 / 题号位置 / 字号变了，就是回归，按模板漂移处理。
3. 任何资源改动后必须跑：
   ```bash
   python3 bump_assets.py
   python3 bump_assets.py --check
   node --test test/version-sync.test.js
   node tools/verify_nav.mjs
   ```
   `test/version-sync.test.js` 已硬校验 **index / exam / drill / wrong / jiangyi 五页** 的 `?v=` 同值；`tools/verify_nav.mjs` 末尾也会再查一次五页同值（本次本地 **38/38** 通过）。`bump_assets.py` 的 `HASH_FILES` / `BUMP` / `HTML` 都包含 `index.html`，一次 bump 覆盖五页。不靠人记。

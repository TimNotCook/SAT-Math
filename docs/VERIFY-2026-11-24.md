命令：`node tools/narrow_check.mjs <baseUrl> docs/ui-shots`

### 改前（线上 42b41e4 实测，问题真实存在）

| 宽度 | 页面 | 横向滚动 | 出框/被裁 |
|---|---|---|---|
| 655 | 抽查开考 | 无 | 「设置」右边界 700 > 655，整颗在屏外，点不到 |
| 390 | 真题练习列表 | 无 | 导航「错题回顾」右 418、「模考」右 485 被裁；「设置」右 539 整颗出屏 |
| 390 | 抽查开考 | 无 | 「模考」右 434 被裁；「设置」右 488 出屏 |
| 390 | 模考答题 | 无 | `#tbSection` 被计时器压住，只剩「Section 2, M」 |

根因不是页面级横向滚动，而是页头 `.appbar-inner` 在 bluebook 层被 `flex-wrap:nowrap` 锁死（`bluebook.css:26`），
导航自己内部可横滑但右侧那两个按钮没有退路；`app.css` 的 `.exam-modules{justify-content:center}` 又让溢出从两边同时发生，
左侧还回不去（`scrollLeft` 只能往右滚）。

### 改了什么

`bluebook.css` 末尾新增两段（不新建覆盖文件，原文件自带「edit the selector directly」约定）：

- `@media (max-width:760px)`：单行收紧——间距 28→14、内边距 28→16、藏 `bankpill`（题库胶囊在手机上让位给导航与设置）、
  `退出`/`设置` 用 `order` 固定到最右；`.drill-resume` 改 `nowrap + 省略号`。
- `@media (max-width:640px)`：一行真放不下才折两行——第一行品牌 + 退出 + 设置，第二行导航整行、`flex-start`、可横滑；
  答题页考场条改回单行 flex，`#tbSection` 走 `text-overflow:ellipsis`。
- `drill.html` / `exam.html` / `wrong.html` 的 `bluebook.css?v=` 升到本次内容哈希，避免旧样式被缓存。

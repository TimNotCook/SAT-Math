# 讲义复习 1.1–1.5「选项是图」清单 + JY1-040 选项图数据

更新时间：2026-11-25（数据侧，开发者）。范围：`data/jiangyi.js` 里 1.1–1.5 共 **45 题**。
姊妹文档：`docs/jiangyi-reconcile.md`（数字/缺口台账）、`docs/jiangyi-tables.md`（表格题清单）。

## 一句话结论

1.1–1.5 里**「选项本身是四张图」的只有两题**：`JY1-005`（p9 #5）和 `JY1-040`（p30 #1）。
另有 `JY1-042`（p32 #3）是**四张选项表**，已由 α 用 `choiceTables` 修好，留作对照项。
其余 42 题选项全是文字/数字，**不需要选项图**——包括 4 道 `type` 写着 `mcq-graph`、但图只在题干、选项仍是文字的题（p18 / p31 / p34 / p35），它们不是缺口，别再当缺口报。

**两题的共同现状（2026-11-25 晚已闭环）**：选项图通路已由编程者 `6cc86cd` 定名 **`choiceFigures`** 并接线，
`JY1-040` 当轮即接；`JY1-005` 本轮接上同一字段（`{"A":{"vector":"JY1-005#A"}…}`），两题选项里现在都是四张图。

## 判据（怎么扫的，别人可复现）

一条题命中「选项是图」需同时满足：

1. `choices` 是 `["A","B","C","D"]` 这类纯字母占位（真选项在别处）；
2. 原页目视确认 A–D 位置上印的是图，不是文字。

单用第 1 条会误报：`JY1-037`（p28 #9）的选项是数字 `2 / 4 / 5 / 6`，同样四个字符，但不是图。
单用「页面嵌入图数量」也会误：整本讲义每页 20–50 张 278×295 的水印小图，判不出图选项。

### JY1-040 逐图参数（本轮量原页定稿）

原页 p30 的四张选项图是**嵌入 JPEG 位图**（页面 187 张图、无矢量线条），本轮按 xref 逐张抽出、按页内 bbox 定位：
A = xref 3463（左上）、B = xref 3466（左下）、C = xref 3467（右上）、D = xref 3470（右下）。
逐张拟合直线像素轨迹 + 网格间距，得：

| 选项 | 升/降 | 斜率 | y 截距 | 影在哪侧 | 格距 | 对应不等式 |
|---|---|---|---|---|---|---|
| A（答案） | 降 | −0.60 | 3.00 | 线下 | 1 | y ≤ 3 − 0.6x ✓（题干 5y + 3x ≤ 15） |
| B | 降 | −0.60 | 3.00 | 线上 | 1 | y ≥ 3 − 0.6x（同一条线翻边） |
| C | 升 | +0.60 | 2.98 | 线下 | 1 | y ≤ 3 + 0.6x（斜率符号错） |
| D | 升 | +0.60 | 3.05 | 线上 | 1 | y ≥ 3 + 0.6x（斜率 + 影都错） |

> 旧 spec 的 B/C/D 是 `b = 3.6 / 4 / 4.2`、B 影在上，和原页对不上（C、D 截距高了近 1 个单位，原页四条线其实都过 y = 3）。
> 本轮四条线统一到 b = 3；B 与 A 只差「影在哪侧」，正是原书那对翻边干扰项。格距也由 0.5 改成原页的 1（0.5 画出来比原书密一倍）。

### JY1-005 逐图参数（本轮量原页定稿）

p9 的四张选项图是**页面上的矢量线条**（非位图，`get_drawings` 只拿到公式字形，图在线段操作里），
故改用 400dpi 整页渲染定位：四格各 **8×8 格、格距 0.5**（每 2 格 = 1 单位），原点居中，x 与 y 均 −2…2，只标 `1`。
逐格拟合直线（半径 4px 迭代内点 + 以格心为标尺换算成单位）得：

| 选项 | 斜率 | y 截距 | x 截距 | 与 ax + by = b（0 < a < b）|
|---|---|---|---|---|
| A | −1 | 1 | 1 | ✗ a = b，违反 a < b |
| B | −1 | −1 | −1 | ✗ 截距在负半轴 |
| C（答案，p191 亦写 C） | −0.5 | 1 | 2 | ✓ a : b = 1 : 2 |
| D | −2 | 1 | 0.5 | ✗ x 截距 < 1，a > b |

> 旧 spec 的 B 用 `b = 1.5`、D 用 `b = 2`、四格坐标框取 −3.2…3.4（画出来比原页多出 5 列、原点不居中），
> 本轮全部按原页改成 −2…2 / step 0.5 / 四格同尺寸（272×252，内区 188×188 → 方格 23.5px 正方）。
> 网格底色沿用全册统一 `GRID = #D7DEE7`（比原页扫描的灰更浅），与其余讲义矢量图保持同一套观感，不作第二种线色。

## 选项图接线（字段已由编程者定名，两题都已落地）

```js
// 字段（唯一一套命名，编程者 6cc86cd 定）：
"choiceFigures": {"A":{"vector":"JY1-040#A"}, "B":{"vector":"JY1-040#B"}, …}

// 渲染入口（choice-figures.js 调用；一个选项一张图）
JY_FIG.renderPanel('JY1-005', 'A')   // 返回 '<svg …>'；非 quad / 无该面板时返回 ''
```

- 两题的 `figure` 字段都已删除：JY1-005 / JY1-040 的图**只在选项里**出现，题干下方不再重复挂一张 2×2 合成图。
- `choices` 仍是 `["A","B","C","D"]`，字母只用来取面板；数据侧不新增第二套 spec id。
- `JY_FIG.render(id)`（整张 quad）保留给需要 2×2 合成图的场合，本两题不再使用。

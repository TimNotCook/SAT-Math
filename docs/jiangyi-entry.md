# 讲义复习 · 数据层（开发者这一行）

## 这是什么

新板块「讲义复习」的题库，独立文件 `data/jiangyi.js`，**不并入 `questions.js`**（那一千行已经很难读了，再混两百多道谁也说不清谁是谁）。

- 单元：U1 Algebra / U2 Problem Solving and Data Analysis / U3 Advanced Math / U4 Geometry and Trigonometry
- 小节：真实小节号 `1.1`–`4.5`（共 24 节），筛选、完成度都靠它算
- id：`JY1-001` … `JY4-0xx`，跟现有 `U1-01` 那套完全不混号
- `source`：`讲义 p{页} #{页内题号}` 三段齐全，题卡上就显示成 `3.4 · p131 #12` 这一形
- `answer`：照抄答案页 p191–196，**不自己算**

## 为什么先出对账表

`docs/jiangyi-reconcile.md` 是入口：**各节应有数 = 该节在答案页的最大题号**。已录数必须等于它，差一道都不算完成。表由 `tools/gen_jiangyi_reconcile.py` 从 `data/jiangyi_answers.json`（答案页逐节抄下来的键）和 `data/jiangyi.js`（已录条目）自动生成，手改无效——数据一动表就跟着动。

「例题不录」不是一句口号，是一条执行得起来的规则：答案页上查不到题号的段落一律不录，`test/jiangyi.test.js` 会挡住任何超出答案页最大题号的条目。讲义的 Example 例题答案不在 191–196 里，所以自动出局，顺带也挡住了「看着像题」的段落被夹带进来。

## 四道校验怎么落地

| 校验 | 人工 | 自动 |
|---|---|---|
| 题干文本 | 回原页逐句比对，alt 词、单位、变量名照原样 | `test/jiangyi.test.js`：非空、无 `f (x)`、问号前无多余空格 |
| 四个选项 | 回原页逐项比对（含 A–D 顺序） | 恰好 4 个、不空、答案落在 A–D |
| 图形与图表 | 只描几何，不裁扫描页（整本讲义带 TESTDAILY / SAT教研组 水印） | 引用的矢量 spec 必须存在；不许挂 `image`、不许进 `figure_crops` |
| 答案 | 与 p191–196 逐字核对 | `answer` 必须逐字等于答案键 |

每题还要留一张原页对照截图 `docs/jiangyi-proof/{id}.png`（定名即题号），缺图测试直接红。抽查在这里没有意义——初录就是最容易错的时候，所以按 100% 过。

## 图形为什么自建渲染器

`data/jiangyi_figures.js` 自带一个画平面的小渲染器（`JY_FIG.render(id)`），因为讲义这几张图的轴样式和 `figures.js` 默认形态不同：轴在原点交叉、箭头尖端落在框边、`x`/`y` 印在箭头外侧、原点写 `O`、刻度按原书抽着标（16 的网格只标 0/4/8/12/16）。几何全部由不等式或方程算出来：

- `JY1-001`：过 (0,8)、(12,0) 的直线，x/y 各 16 格、每 4 标一次
- `JY1-002`：`6x + By = 42`，B=14 → y 截距 3、x 截距 7
- `JY1-005`：四选图。答案页写 **C**，所以 C 是「y 截距恰为 1、斜率 −a/b ∈ (−1,0)、x 截距 2」那张；A/B/D 分别是斜率 −1、截距 1.5、斜率 −2 的错图
- `JY1-009`：line k 过 (0,5)、(2,0)，即 y = −5/2 x + 5
- `JY1-040`：p30 四选图，原书排法是 **A 左上 / C 右上 / B 左下 / D 右下**（不是 A B / C D），所以 spec 里用 `order` 指定印法。**四张图的线都过 y 截距 3、|斜率| 0.60、格距 1**（2026-11-25 按 p30 四张嵌入图 A=xref3463 / B=3466 / C=3467 / D=3470 逐张拟合重校；旧口径 B=3.6、C=4.0、D=4.2 是错的），四题只差「升/降」与「影在哪侧」：A 降 + 影下（正确图 y ≤ 3 − 0.6x）、B 同线影上、C 升影下、D 升影上。单格渲染入口 `JY_FIG.renderPanel('JY1-040', letter)`；逐图参数见 `docs/jiangyi-choice-figures.md`
- `JY1-041`：p31 虚线 y = 1 − 4x（严格不等号所以画虚线），阴影在线右上方；网格 ±8、每 2 标一次
- `JY1-044`：p34 只有十字轴和 I/II/III/IV 标号，没有网格（`type:'quadrants'`）
- `JY1-045`：p35 网格 ±10，虚线 y = x 与实线 y = 4，阴影是两块半平面的交（`shade` 传数组即求交，不是各画一块）；原点在原书不标字，spec 里也不标

新增的三种渲染能力（`shade` 半平面裁剪、`dash` 虚线、`quadrants` 象限图）只加在 `jiangyi_figures.js`，`figures.js` 一行没动。

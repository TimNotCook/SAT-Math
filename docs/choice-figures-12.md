# 选项图矢量重画 · 12 张（TD-22-14 / TD-33-18 / TD-33-19）+ SR-232·U1-01 复用

更新时间：2026-11-25。文件：`figures.js`（渲染器）、`data/figures.js`（spec）。

## 做了什么
旧版选项图只有 `{kind,xInt,yInt,xmax,ymax}` 五个字段，画出来是 300×300 的简化格子：
没有刻度数字、没有原点 `O`、直线只连两个截距（不像原书那样穿出网格）、曲线靠手调系数。

现在 20 条 spec 全部改成**完整坐标平面**写法（`x`/`y` 轴定义 + `series`），交给题目大图那套
`chart()` 渲染器统一出图：

- 网格 + 刻度数字（步长与标注列表可分别给，和原书「只标部分格线」一致）
- 轴在原点交叉（`axesAt:'zero'`），原点印 `O`
- 轴箭头为实心三角，**箭头尖端落在边框上**
- 线/曲线用 `clipPath` 切在坐标系内，越界即被边框裁掉（原书「线穿出网格」的效果）
- 新增 `series.kind:'poly'`：按根 `sign·k·∏(t−r)` 采样，`k` 自动归一化到框内，不再出现
  旧版 `v/800` 那种拍脑袋缩放

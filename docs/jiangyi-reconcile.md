## 录入规则（可执行，已写进 test/jiangyi.test.js）

1. 答案页（p191–196）里查不到题号的段落，一律不录——Example 例题就死在这一条上。
2. 每题 `source` 必须三段齐全：`讲义 p{页} #{页内题号}`。
3. 每题 `answer` 必须逐字等于本表答案键；选择题的答案必须落在 A–D 之内。
4. 每题必须有一张原页对照图 `docs/jiangyi-proof/{id}.png`，缺图即视为未录。
5. 图形只允许矢量 spec，`images/` 下不许出现讲义裁图（整本讲义带 TESTDAILY / SAT教研组水印）。
